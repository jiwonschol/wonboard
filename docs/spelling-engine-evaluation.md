# 한국어 검사 엔진 검토

검토일: 2026-09-09. 새 엔진이나 모델은 아직 설치하지 않았다.

## 제품 기준

Wonboard 자체 코드는 MIT를 유지한다. 외부 코드, 사전, 모델 가중치, 학습 데이터의 조건은 각각 확인한다. 문서는 기기 안에서 검사하며 외부 서비스로 전송하지 않는다. 문체를 다시 쓰지 않고 사용자가 승인한 표현만 바꾼다.

## 후보와 현재 판단

| 후보 | 확인한 조건 | 판단 |
| --- | --- | --- |
| 현재 Hunspell + 한국어 사전 | 엔진 MPL 1.1 선택, wrapper MIT, 사전 GPLv3 | 철자 검사 유지. 사전은 프로그램과 별도 저작물이라는 upstream 설명이 있다. 전체 구성물이 MIT인 것은 아니다. |
| Kiwi | C++ 라이브러리 LGPL 2.1 이상 | 성능 후보지만 단순한 허용적 라이선스라는 요구에는 맞지 않아 신규 도입 보류. |
| PyKoSpacing | GPLv3 | 내장 후보에서 보류. |
| TrainKoSpacing | 저장소 Apache 2.0. README는 학습 말뭉치 재배포 제약을 명시 | 추가 조사 우선 후보. 모델 배포 조건, 데이터 사용 조건, 브라우저 이식 비용을 확인하기 전 도입하지 않는다. |
| fiveflow/roberta-base-spacing | 공개 모델 카드에서 명확한 라이선스를 확인하지 못함 | 가중치 사용·재배포 권한 확인 전 보류. 변환판의 라이선스 표시만으로 원본 권리를 판단하지 않는다. |

현재 배포 고지는 `public/spelling/NOTICE.md`를 따른다. 특히 emscripten-wasm-loader는 패키지에 독립적인 LICENSE 파일이 없으므로 공개 배포 전 고지 조건을 확인해야 한다. 이 문서는 법률 의견이나 전체 의존성 감사 완료 선언이 아니다.

## UI 변경

추천 표현을 누르면 선택만 한다. '바꾸기'를 눌러야 본문에 적용하고 다음 항목으로 간다. 직접 입력, 건너뛰기, 이번 검사에서 무시, 사용자 사전 추가를 유지한다. 문맥 안의 검사 표현을 강조한다.

현재 엔진은 문장 단위 띄어쓰기를 검사하지 않는다. 검사 시작과 완료 화면에서 이 범위를 명시한다. 사전에 없는 단어를 반드시 틀린 표현이라고 단정하지 않는다.

## 엔진 도입 또는 자체 구현의 다음 검증

1. 코드뿐 아니라 실제 배포할 모델·사전의 출처와 재배포 권한을 확인한다. 확인 불가 후보는 채택하지 않는다.
2. 라이선스를 확인한 후보를 문장 단위로 평가한다. 직접 작성한 띄어쓰기 오류, 정상 문장, 게임 고유명사, 구어체, 한영 혼용 사례를 사용한다. 일반 코퍼스를 허가 없이 복사하지 않는다.
3. 정상 문장 오탐, 오류 탐지, 제안 정확도를 따로 기록한다. 브라우저의 다운로드 크기·메모리·검사 시간도 측정한다. 현재 공개 벤치마크 수치를 Wonboard 성능으로 제시하지 않는다.
4. 적합한 후보가 없으면 MIT 코드와 출처를 관리하는 자체 규칙부터 구축한다. 지원 범위를 명시하고, 몇 개 규칙의 성공을 일반적인 한국어 띄어쓰기 해결로 발표하지 않는다. 전체 모델 학습은 별도 데이터·비용 계획이 필요하다.

이번 변경으로 띄어쓰기 검사가 구현된 것은 아니다. 신규 의존성, 모델 다운로드, 외부 전송, 배포는 하지 않았다.
