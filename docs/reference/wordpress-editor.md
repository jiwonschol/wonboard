# WordPress 편집기 화면 대조

## 이후 승인된 디자인 변화

지원이 2026-09-05 초기 작성기에 만족한다고 확인한 뒤, WordPress의 완전 복제에서 벗어나 왼쪽 율리시스식 글 목록과 오른쪽 `글·블록·첨부` 탭을 요청했다. 아래 초기 복제 대조는 이력으로 남긴다. 현재 화면의 248px 글 목록과 300px 설정 패널은 이 새로운 방향을 따른다. 좁은 화면에서 글 목록은 접을 수 있는 서랍이며, 넓은 화면에서는 본문을 밀어내고 나란히 배치한다. 폴더·프로젝트 관리까지 구현했다고 표시하지 않는다.

클리앙 Chrome 글쓰기 화면에서 이미지 개수, 파일 선택/드롭, 별도의 외부 이미지·비디오 주소 입력을 직접 확인했다. 클리앙에 파일을 올리거나 글을 제출하지 않았다. 원보드는 첨부 탭 하나로 통합하고 자동 파일명과 영상 재생 설정을 추가한다. 첨부한 율리시스 화면의 차분한 목록·선택 행·본문 미리보기를 참고했으며, 기존 WordPress 계열 글꼴·툴바를 유지했다. 별도의 이미지 시안을 생성하지 않았다.

데스크톱 1440px에서 목록·본문·첨부가 겹치지 않는지, 기존 너비 948px와 모바일 390px에서 서랍을 닫고 편집할 수 있는지 검사한다. 문구는 `내 글`, `모든 글`, `지난 7일`, `첨부`, 파일명과 영상 설정 등 요청 기능에 한정한다. 클라우드·로그인은 실제 연결이 없다고 표시한다.

2026-09-05 지원이 열어 둔 WordPress Playground의 실제 편집 화면을 정본으로 사용했다. WordPress 7.1 / Twenty Twenty-Five의 현재 화면을 DOM과 스크린샷으로 확인했다. Mobbin 대체 화면이나 생성 이미지를 사용하지 않았다. Gutenberg 코드·스타일·아이콘은 복사하지 않았으며 Manrope는 독립 Fontsource 배포본과 OFL 고지를 사용한다.

기준 너비 948px, 편집기 높이 815px. 원본 스크린샷 아래의 Playground 운영 도구는 제품 화면에 포함하지 않는다. 화면 파일은 이번 작업의 Codex 시각 자료 폴더에 보존했다.

| 비교 항목 | 원본 측정 / 구현 상태 |
| --- | --- |
| 상단 관리 줄 / 문서 도구 줄 | 32px / 64px로 구현 |
| 작성 영역·설정 패널 경계 | x=667px 기준으로 대조 |
| 제목 시작 | x≈33.4, y≈160; Manrope 400, 39.0388px / 43.9187px |
| 본문 시작 | y≈230.06; Manrope 300, 19.3642px / 27.1098px |
| UI 글꼴 | 시스템 글꼴 13px, 한국어는 시스템 fallback |
| 스타일 버튼 | x≈684, y≈296.2; 기본/강조/부제/주석 2열 |
| 기능 차이 | 사이트 관리 메뉴를 문서 목록·새 문서·언어 선택으로 연결. 게시 버튼은 서버 미구현 안내와 함께 비활성화. 로컬 저장 상태를 추가 |

## 아직 완전 일치라고 할 수 없는 부분

- 상단 문서 이름 버튼은 기준 화면에서 원본보다 약 31px 왼쪽에 있다. 원본은 5열 grid, 현재 구현은 3개 flex 그룹이다. 응답형 도구 모음 전체의 배치를 추가로 맞춰야 한다.
- 설정 패널 아래쪽으로 약 1~3px의 누적 간격 차이와 일부 아이콘 형태 차이가 남는다.
- 원본의 전체 블록·상세 설정·키보드 동작을 구현한 것은 아니다. 실제 입력·서식·사진을 지원하는 초기 범위다.
- 원본은 영문 기준으로 확인했다. 한국어는 Wonboard 번역과 레이아웃을 검사했으며 WordPress 한국어판과 문구까지 동일하다는 뜻은 아니다.
- 미리보기·문서 목록 모달의 키보드 초점 관리와 세부 접근성 검증이 추가로 필요하다.

따라서 현재 결과는 실제 WordPress 화면을 측정해 만든 작동하는 초기 편집기이며, 픽셀 단위 완전 복제 완료 판정은 보류한다. 후속 시각 작업도 같은 원본과 같은 크기로 다시 비교한다.
