## 표본과 검증 범위

HN 920개, MoneySavingExpert 996개, Orbi 222개, Quasar 267개를 확보했다. Orbi의 `ㅋㅋ` 한 건이 초기 live-round2 자료와 중복되어 예측 전 제외됐다. 전체 2,572회 요청의 종료 상태가 확인됐고 Quasar의 429 응답 이후 남은 28개는 요청하지 않았다. 결과에 따른 표본 추가는 없었다. 수집 원본은 보존하고 제외 사유를 별도 기록했다.

HN은 2025년 6–8월, MSE는 2025년 1월–2026년 8월, Orbi는 2025년 12월, Quasar는 2026년 6–8월의 접근 가능한 목록 안에서 시드 추첨했다. 인터넷 전체의 대표 표본이 아니며 기술·컴퓨터와 입시 글의 비중이 크다. 글당 첫 25개 공백 구분 단어만 평가했다.

Luna의 독립 초벌 뒤 부모가 모든 원문·정답을 검토하고, 고정 검사기를 각 글에 한 번씩 실행한 다음 모든 첫 제안을 판정했다. 전문가 정답은 아니다. 기존 오류를 일부 남긴 부분 교정은 새 오교정과 구분했고, 허용 띄어쓰기·구어 표현은 필수 수정으로 강제하지 않았다. 필수 구간 도달은 전체 언어 오류 재현율과 다르다. 영어 68/420, 한국어 409/821이므로 낮은 오교정률만으로 검사 완성도를 주장할 수 없다.

## 구현과 보존

이번 수정은 문맥이 검증된 영어 후보 선택과 한국어 감탄사 보호, 기존 분석이 실패한 일부 동사·명사 경계의 복원을 포함한다. 동결 전 관련 테스트 256개, 타입 검사, 데이터 정책 검사를 통과했다. 기존 노출 자료 24,688개 재검사에서는 이전 오교정 6개와 보류 1개를 제거했고 새 명백 오교정과 유효 제안 손실은 없었다. 개발 재검사 결과는 위 새 평가에 합산하지 않았다. 별도 정상 표현 검사에 남은 기존 실패 16개는 해결했다고 주장하지 않는다.

59개 평가 묶음의 고정 입력·검사기 해시 944개와 완료 주석 파일 59개의 해시를 검증했다. 최초 예측과 원본 주석은 보존했다. HN 05의 예측 전 부모 분류 결정이 `stratum` 대신 `kind` 필드에 기록된 사무 오류는 별도 보고 분류·재채점 산출물로 반영했다. 예측을 다시 실행하지 않았다. Quasar 225 주석이 저장소 루트에 잘못 저장된 것은 내용과 해시를 그대로 보존해 지정 폴더로 옮겼다.

수집기 최초 실행의 노출 manifest 해시 검사 불일치는 네트워크 요청 전에 정정했다. Quasar 과거 요청 누락 경보는 `quasar:ID`와 `quasar:BOARD:ID` 비교 오류였고 숫자 ID 대조에서 교집합 0을 확인했다. 별도의 본문 중복 1개는 초기 자료까지 합친 재검사에서 발견해 제외했다. 기준 검사기의 `허가 받아`·`도움 받아서` 2개는 공식 검색으로 확정하지 못해 보류로 남겼고 후보에는 해당 제안이 없다.
