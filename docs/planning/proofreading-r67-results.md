## 다음 개발 근거

한국어에서는 `이거군요 → 이더군요`, `모을라고 → 모으라고`처럼 구어의 뜻을 바꾸는 교정과 `공문서란 → 공문 서란`, `이사가기 → 이사가 기`처럼 단어·어미 경계를 끊는 교정이 남았다. `되있어서 → 되이어서`는 같은 활용 오류가 두 글에 반복됐다. 음식명·브랜드의 잘못된 분리도 있었다.

영어에서는 DeepL을 deeply로 바꾼 두 제안, broadband 약어 bband를 band로 바꾼 제안, rather의 오타 tather를 tether로 바꾼 제안이 명백한 오류다. developi를 develop로 바꾼 제안은 의도가 불명확해 보류했다. 이 자료는 이후 개발 자료로만 사용한다.

## 실행 예외와 증거

최초 한국어 메타데이터에서 과거 선택한 Orbi 식별자 222개를 발견해 본문 요청 전에 무효화했다. MSE 최초 359개도 URL 별칭에 가려진 과거 토론 식별자로 확인해 요청 전에 무효화했다. 한국어는 합친 식별자 제외 원장으로 재추첨했고 MSE는 같은 6개 공개 게시판의 2024년 목록으로 범위를 고정한 뒤 추첨했다. 결과를 보고 표본을 보충하지 않았다.

원격 Luna 외에 기존 수집 에이전트도 독립 주석을 맡았으며, 도구가 모델을 노출하지 않은 부분은 해당 사실대로 기록했다. HN 첫 25행에서는 완료 통보 뒤 4행의 complete 플래그가 수정됐으나 첫 예측 전이었다. 원본을 역복원해 최초 완료 통보의 SHA와 정확히 일치함을 확인했고 원본·수정본·사유를 모두 보존했다. 다른 라벨의 구간 겹침·허용형 등은 첫 예측 전에 고치고 원본과 변경 내역을 분리했다.

영어 수집기는 모든 요청과 결과 파일을 쓴 뒤 마지막 상태 출력의 flush 인자 오류로 종료했다. 추가 요청 없이 본문·원장·고정 선택·응답 해시와 모든 체크포인트를 대조해 누락 0건을 확인했다.

정본은 Git 제외 디렉터리 `local-corpora/historical-goal-2026-09-27/`의 `r67-final-gates.json`, `r67-final-coverage.json`, `r67-damage-register.json`, `r67-mandatory-changes.json`, `r67-evidence-hashes.json`이다. 제품 고정 파일 SHA256은 `32dae3eeec6a711f539d845a81deee5a5b62cf562fb57c21f1f82cda59497575`다. 입력 630개 해시, 고정 검사기 및 완료 주석 파일 90개를 검증했다.
