# 두 번째 프로토타입의 근거와 평가 변경

2026-09-10 확인. 아래 짧은 규정 인용 외에 해설·사전 자료는 복제하지 않았다. 코드와 예문은 자체 작성했다. 규칙의 존재와 자동 분석의 정확성은 별개다.

* 제41항: “조사는 그 앞말에 붙여 쓴다.” 제42항: “의존 명사는 띄어 쓴다.” [국립국어원 직접 답변](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=306301). 예: `공팟에서`, `읽는 것을`. 미등록 명사도 명시한 조사 조합을 보존한다. 조사 목록에 섞인 구어적 어미를 미등록 명사의 조사로 해석하지 않는다.
* 제34항 붙임 2: “‘하여’가 한 음절로 줄어서 ‘해’로 될 적에는 준 대로 적는다.” [공식 규범 검색 결과](https://www.korean.go.kr/kornorms/m/m_regltn.do), [직접 상담 사례](https://korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=6199&mn_id=217&pageIndex=1). 예: `저장하였어요 → 저장했어요`. 두 형태 모두 인정한다.
* 제35항 붙임 2의 ㅚ+어 축약은 [국립국어원 상담 사례](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5827&mn_id=217&pageIndex=1)로 확인했다. 원문의 짧은 구절: “준 대로 적으므로”. 예: `되어 → 돼`. 일반 모음 축약도 규범 제34·35항의 원리를 구현하며, 모든 불규칙 활용을 처리했다고 주장하지 않는다.
* 제47항: “보조 용언은 띄어 씀을 원칙으로 하되, 경우에 따라 붙여 씀도 허용한다.” [국립국어원 설명](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=324945). `열어주세요`를 확정 오류로 둔 시험지를 수정했다. 대신 `열고있어요`를 오류 사례로 두고, 정상 자료에 `열어주세요`를 넣었다. 기존 점수와 직접 비교하지 않고 같은 수정 자료에 구버전/신버전을 모두 실행한다.

규범 본문 직접 열기는 여전히 실패했지만 검색 결과와 국립국어원 개별 상담 페이지를 통해 위 내용을 확인했다. 자료 전체 200문장의 어휘 정답까지 모두 외부 확인한 것은 아니다. 나머지 unverified 표시는 유지한다. 특히 문맥에 따라 다른 뜻으로 해석 가능한 표기와 -걸의 어미/의존명사 구별은 미해결이다. -걸 제안은 ambiguous로 명시한다. 본 프로토타입은 완전한 문맥 분석기가 아니다.

재사용 평가 자료는 미사용 홀드아웃이 아니다. `fresh-v2.json`의 새 20문장은 이번 구현 후 고정한 별도 평가 자료이며 같은 작성자가 만들어 독립 평가는 아니다. 평가 결과를 본 뒤 해당 엔진을 다시 수정하면 재사용 사실을 기록해야 한다.
