# 작성 공간과 배포물의 수명 계약

이 문서는 [파일 보관·공유 이슈 #9](https://github.com/jiwonschol/wonboard/issues/9)와
[전체 추적 #12](https://github.com/jiwonschol/wonboard/issues/12)의 확정 제품 계약이다.
지원의 2026-09-16 결정(Buzz triage 이벤트
`f44ed9d31694e26a509c57e6408baa3300c48c733cff9416405b568cfa43bc2a`)을 반영한다.
이 주제에서 이전 계획의 제안과 충돌하면 이 계약을 따른다. 계약 확정은 구현·배포 완료를 뜻하지 않는다.

## 제품의 목적

원보드는 사용자가 커뮤니티에 글을 배포하기 전에 초안을 작성하는 개인 워드프로세서다.
글쓰기가 중심이고 파일 보관함은 작성과 배포를 돕는다.
초안을 정리하는 행동과 이미 배포한 자료를 회수하는 행동을 분리한다.

## 삭제와 공개 주소

| 사용자의 행동 | 작성 공간 | 이미 배포한 자료 |
| --- | --- | --- |
| 글을 휴지통에 넣거나 영구 삭제 | 기존 글 휴지통 계약에 따라 정리 | 공개 사진·파일 주소와 공유 글은 유지 |
| 작성 공간에서 파일을 제거 | 해당 작성 공간의 참조를 제거 | 공개 주소와 공유 글이 필요한 바이트는 유지 |
| 보관함에서 배포물 철회·삭제를 명시적으로 선택 | 다른 글이 필요한 자료는 보존 | 선택한 배포물의 공개 접근을 종료 |

글 삭제 확인 화면에서 공개 주소 철회를 함께 선택하게 하지 않는다.
이전의 “사진 주소도 삭제” 또는 “공유 주소도 끊기” 체크박스 제안은 이 흐름으로 대체한다.
구현은 기존 체크박스의 제거와 보관함의 독립 관리 경로를 함께 다룬다.
관리 경로가 구현되기 전에 기존 철회 기능만 없애서 사용자가 배포물을 관리할 수 없게 하지 않는다.

배포물 정리는 사용자가 보관함에서 결정한다. 글 삭제·30일 만료·고아 파일 정리가
배포물의 유효 참조를 무시하고 공개 바이트를 지우면 안 된다.
다른 문서나 공유본이 필요한 바이트가 남는 경우 그 이유와 보관 용량을 구분해 표시한다.
외부 커뮤니티에 사용자가 올린 글 자체를 원보드가 대신 삭제하지 않는다.
이미 내려받은 사본이나 외부 서비스의 복제본까지 회수한다고 약속하지 않는다.

## 독립된 공유 글

공유 글은 공유 시점의 고정본이다. 초안 수정·삭제·휴지통 만료와 독립적으로 보존한다.
“공유 페이지 업데이트”를 명시적으로 실행할 때만 내용이 바뀐다.
공유의 만료·철회는 공개 접근을 끝내며 마지막 고정본은 비공개로 보존한다.
공유본 자체를 제거하려면 보관함에서 별도 삭제를 선택한다.

스냅샷의 사진은 게시용 재인코딩본을 사용한다. 기존 사진 재게시가 같은 공개 주소의
사진을 바꾸더라도 고정 공유 글의 내용은 바뀌지 않아야 한다.
갱신 중 실패와 옛 버전 자산의 수명은 구현 계획과 시험으로 다루되,
유예 때문에 만료·철회된 공유가 계속 공개되는 동작은 허용하지 않는다.

## 백업과 영상

문서 ZIP에는 그 글이 참조하는 첨부 파일의 바이트를 포함한다.
기존 256MiB 상한을 유지하며, 필요한 파일이 빠지거나 상한을 넘은 백업을 성공으로 표시하지 않는다.
첫 버전은 보관함 전체 일괄 백업을 제공하지 않고 독립 보관 파일의 개별 다운로드를 제공한다.

공유 글의 영상은 원래 영상으로 가는 링크로 표시한다.
기존 편집기 및 커뮤니티 내보내기의 영상 기능을 이 결정만으로 제거하지 않는다.
수신 커뮤니티의 링크 인식·미니플레이어 지원은 해당 사이트에 달려 있으며,
모든 게시판에서 인라인 재생된다고 보장하지 않는다.

## 기존 결정 및 검증 경계

파일당 20MiB, 공유 기본 만료 없음, 링크를 가진 사람의 접근, 사용자 지정 기한,
PNG/JPEG 외 업로드 파일의 다운로드 제공, 기기와 Sites 간 자동 동기화 없음은 유지한다.
공개 주소 유지가 플랫폼의 무기한 가용성이나 검증되지 않은 계정 저장 총량을 보장하지는 않는다.

로컬 구현·시험·스키마 및 마이그레이션 파일 작성과 열린 PR로 검토하는 작업을 진행한다.
운영 DB 적용·배포·머지는 이 문서만으로 승인되지 않는다.
실제 계정·CDN·macOS·Windows 결과는 각 환경에서 검증한 증거와 함께 별도로 보고한다.
