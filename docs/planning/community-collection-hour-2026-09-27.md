# 인터넷 게시글 수집과 첫 비교

실제 공개 게시글 198개를 추첨·보관하고, 151개에 Luna 주석과 기존 검사기의 첫 결과를 남겼다. 나머지 한국어 47개는 본문을 모델에게 보여 주거나 검사기에 입력하지 않은 예비 표본이다. 이번 결과에서는 한국어의 복합 띄어쓰기 누락과 잘못된 분리, 영어의 축약형·약어 처리가 우선 개선 대상으로 드러났다. 현재 검사기가 인터넷 글에 충분히 맞는다고 판단할 근거는 얻지 못했다.

목적은 한국어·영어 인터넷 글에서 기존 검사기가 놓치는 수정과 잘못 제안하는 수정을 확인하는 것이다. 검사기 코드는 고정했으며 이번 회차에서는 수집·판정·비교만 수행했다. 수집과 판정은 2026년 9월 27일 15:33 KST에 시작했고, 첫 검사는 16:19 KST에 저장했다. 이후 정상 라벨과 제안의 불일치를 검토하고 결과를 보존했다. 수집·판정·사후 검토는 약 53분 진행했으며, 추가 수집보다 확인된 실패 유형의 개선이 우선이라고 판단해 회차를 마쳤다.

## 수집 범위와 추첨

한국어 출처는 [와플보드 2026년 9월 순위](https://waffleboard.io/ranking)를 근거로 정했다. 이번 평가 자료는 개드립 21개, 보배드림 21개, 82쿡 24개, 오르비 24개, 퀘이사존 23개로 총 113개다. 본문을 얻지 못한 5개는 다른 글로 바꾸지 않고 접근·추출 기록에 남겼다.

영어는 Reddit의 Parenting, sysadmin, DIY, AskMen, NoStupidQuestions에서 38개를 확보했다. 본문 발췌 30개와 제목 8개다. Reddit의 방문 규모는 앞 회차에서 [Similarweb 자료](https://www.similarweb.com/blog/research/market-research/most-visited-websites/)로 확인했으며, 이 하위 게시판들이 방문 순위 상위라는 뜻은 아니다. 확보된 후보 집합은 43개 URL의 부분 목록이고, 웹 도구의 목록 스냅샷은 1~3주 전이었다.

공개 목록에서 후보 URL을 저장한 뒤 `SHA256(seed + newline + URL)`의 오름차순으로 추첨했다. 시드는 `wonboard-community-hour-20260927-v2`다. 한국어는 출처별 최대 24개, 영어는 최대 8개이며, 이전 회차의 URL과 발췌문 해시를 제외했다. 본문은 첫 25개 공백 구분 단어 이하의 연속 발췌다. 문장 끝이 잘렸다는 이유로 문장을 완성하거나 오류를 만들지 않았다.

이는 접근 가능한 목록 안의 재현 가능한 추첨이다. 인터넷 전체의 확률 표본이나 방문량 가중 표본이 아니며, 긴 글 전체의 정확도도 측정하지 않는다. 한국어 본문 113개 중 20개는 1~4단어, 24개는 5~14단어, 69개는 15~25단어다. 한글과 영문이 함께 들어 있는 글은 25개, 자모가 들어 있는 글은 18개다. URL만 있는 본문까지 포함하면 영문 포함 표본은 30개다.

공지·약관·홍보·인용문과 링크만 있는 글은 일반 사용자 글의 주 평가 분모에서 분리한다. 추첨 결과를 좋은 문장이나 오류 많은 문장으로 교체하지 않는다. 오르비 1개에서 투표 양식이 본문 안에 포함된 것을 DOM으로 확인해 예측 전에 제거했고, 수정 전 원문도 보존했다.

## 판정과 평가의 경계

원격 `gpt-6-luna`가 원문을 보고 수정 구간, 허용 대안, 미등록 검토 대상, 보존할 이름·코드를 주석했다. 모델이 문장을 통째로 다시 쓰게 하지 않고, 원문에 정확히 존재하는 구간의 최소 대체를 코드로 조합했다. 반복 문자열의 위치, 중복·겹침, 출력 형식, 허용형을 예측 전에 확인한다.

초벌 판정에는 같은 문장 안의 띄어쓰기 누락, 다른 글의 표현을 잘못 주석한 경우, 설명 문자열을 boolean 필드에 넣은 경우가 있었다. 영어에서는 `ive`만 고치고 같은 문장의 `Im`을 놓치기도 했다. 부모 에이전트의 원문 검토와 기계 검증 결과를 Luna에 돌려주어 예측 전에 보강했다. 따라서 이 라벨은 무검토 Luna 원출력이나 독립 전문가 정답이 아니다.

필수 수정과 허용 표기 변경을 구분한다. 예를 들어 숫자와 단위의 붙임 허용, 보조 용언의 허용형을 정답 대안에 반영한다. [국립국어원 제50항](https://www.korean.go.kr/kornorms/m/m_regltn.do)은 전문 용어의 붙임도 허용하므로, 의료·노동·컴퓨터 용어의 띄어쓰기가 불확실한 항목을 무조건 오류로 확정하지 않는다. 보류 항목의 존재와 수는 숨기지 않는다.

첫 후보의 성공은 **주석된 필수 수정들을 만들 수 있는가**를 뜻한다. 아직 주석하지 못한 언어 오류가 없다는 보장은 없다. 정상 라벨과 제안이 다르다는 사실도 곧바로 실제 오교정으로 확정하지 않고, 해당 제안을 별도로 검토한다. 미등록 알림은 수정안 오교정과 분리한다. 미등록 주석의 완전성은 검증하지 않았으므로 전체 미등록 회수율을 주장하지 않는다.

## 최초 결과

검사 시점 저장소 커밋은 `3f061ab60cdaee73e74ca05f329a07b06682fcec`이다. 검사기·사전·평가 파일 13개의 해시를 입력과 함께 고정했다. 총 151개의 입력·주석을 기계 검증했고 형식·구간 오류는 0건이었다. 이는 언어 판정이 전부 옳다는 뜻은 아니다.

주 평가에서는 공지·약관·홍보·인용 10개를 제외했다. 한국어 103개 중 링크만 있는 5개는 언어 평가 불가로 남겼다. 아래 수치는 수정해야 한다고 주석한 글을 기준으로 한 **잠정 비교**이며, 인터넷 전체 정확도나 전문가 정답 대비 정확도가 아니다.

| 일반 사용자 글 | 103 | 38 |
| 필수 수정 있음 / 정상 / 판정 보류 / 평가 불가 | 47 / 30 / 21 / 5 | 8 / 28 / 2 / 0 |

첫 후보를 골라 적용하는 집계는 잘못된 다른 제안을 사용자가 무시할 수 있다고 가정한다. 따라서 자동으로 전부 적용했을 때의 품질과 다르다. 공지 등을 포함한 전체 한국어 113개의 필수 수정 라벨은 49개이고, 첫 후보로 모두 만들 수 있는 글은 동일하게 10개다.

### 정상 라벨과 제안이 달랐던 6개 재검토

최초 라벨·예측·집계는 고치지 않았다. 예측을 본 뒤의 판단은 `post-prediction-adjudication.json`에 따로 저장한다.

| 원문 → 검사기 제안 | 사후 판단 |
| --- | --- |
| `통제받고` → `통제 받고` | 잘못된 분리로 판단. 국립국어원 용어 자료의 `통제받다` 용례와 피동의 `-받다` 결합 원칙을 해당 문맥에 적용한 판단이다. |
| 인명 `걸걸중상` → `걸 걸 중상` | 이름을 분리하는 오교정. |
| `이쁘다는건지` → `이쁘다는 건지` | 유효한 띄어쓰기 수정. Luna의 정상 라벨이 오류를 놓쳤다. |
| `개땡기네` → `개 땡기네` | 비표준 속어를 어디까지 고칠지 불확실해 판정 보류. |
| 명사 `rip-off` → `ripoff` | 둘 다 허용되는 표기. 필수 교정은 아니지만 틀린 단어로 바꾼 것으로 세지 않는다. |
| 바닥재 문맥 `lvp` → `lap` 등 | 바닥재 약어를 무관한 단어로 바꾸는 오교정. |

판단 근거는 [국립국어원 용어 자료](https://kli.korean.go.kr/term/trgtWord/indexTrgtWord.do?trgtWordNo=2022255), [WSU의 구동사와 명사 표기 설명](https://public.archive.wsu.edu/brians/public_html/errors/phrasal.html), [Shaw의 LVP 용어 설명](https://costco.shawfloors.com/flooring/how-to/vinyl-how-to-s/look-feel/luxury-vinyl-plank-and-tile)이다. 이 6개에서는 한국어 2개와 영어 1개의 오교정, 라벨 누락 1개, 허용형 차이 1개, 보류 1개를 구분했다. 원래의 불일치 비율을 그대로 오교정률로 부르면 안 된다. 오류 라벨이 붙은 글에도 아래와 같은 오교정이 있어, 이 3개가 전체 오교정 수를 뜻하지도 않는다.

### 개선 우선순위

1. **정상 조사·이름·약어를 망가뜨리는 제안을 줄인다.** `엄마한테는`에 `엄마한 테는`, `맞춰져있다보니`에 `맞춰 져있다 보니`를 제안했다. 영어에서는 `i'd`에 `id`, `ive`에 `vie`를 첫 후보로 제안했다. 단어 간 거리나 부분 규칙이 문맥보다 앞서는 경우를 먼저 다뤄야 한다.
2. **여러 띄어쓰기 오류가 붙은 한국어 구간을 처리한다.** `챙기는거아닌가`와 `자기부모만`은 필요한 띄어쓰기 수정 없이 미등록 알림으로 남았다. `자주했나봐`에는 `자주했나 봐`만 제안해 앞의 경계를 놓쳤다. 특정 게시글 문구를 사전에 추가하는 것만으로 해결했다고 보지 않는다.
3. **영어의 축약형·문장 첫 대문자·관사와 약어 문맥을 다룬다.** `ive`/`Im`의 축약형, `an US company`의 관사, 문장 첫 `do you ask`의 대문자 수정이 누락됐다. 인터넷 약어 `atm`에는 `tam` 등을 제안했다. 사용자가 실제로 쓴 문맥에서 필요한 교정과 보존할 표현을 나누어야 한다.

Luna는 다량의 초벌 주석에 사용할 수 있었지만, 이번에 실제 누락이 확인되어 단독으로 최종 정답을 확정하는 용도로는 부족했다. 불일치와 애매한 사례의 별도 검토를 유지한다. 추가 수집만 늘려도 위 문제가 해결되는 것은 아니므로 이번 수집을 마치고, 다음 구현은 이 실패 유형부터 시작하는 것이 적절하다.

이 자료로 개선해야 할 대상을 고른 뒤에는 별도 예비 표본으로 첫 결과를 확인한다. 이번에 본 글의 수정 전후 점수는 개발 과정의 회귀 확인으로만 사용한다.

## 이후 개선을 위한 예비 표본

한국어 47개를 별도 보관한다. 보배드림 11개, 오르비 12개, 퀘이사존 12개는 같은 목록의 미선정 URL 해시 순서에서 뽑았고, 개드립 12개는 관찰된 다음 페이지에서 중복을 제외하고 추첨했다. 이 본문들은 결정론적 수집·중복 검사만 통과했으며, 부모 모델과 판정 모델에게 원문을 표시하지 않았다. 라벨과 검사기 예측도 없다.

향후 검사기 후보의 코드·데이터 해시를 먼저 고정한 뒤 이 자료를 열어 판정하고 첫 예측을 저장해야 한다. 같은 날·같은 출처 계열의 보류 자료이므로 새 시기나 새 출처로의 일반화를 증명하는 자료는 아니다. 이전부터 검토한 표본을 이 예비 자료에 섞지 않는다. 영어 추가 탐색 중 이미 노출된 7개는 별도 미라벨 개발 자료로 보관하며, 198개 추첨 표본이나 47개 미노출 예비 표본에 합산하지 않는다.

## 보존 위치와 실행 부담

원문·목록·접근 실패·Luna 최종 라벨·예측 전 피드백·해시·최초 예측은 Git 제외 경로 `local-corpora/community-hour-2026-09-27/`에 보관한다. `protocol.json`, `sampling-audit.json`, `input-freeze.json`, `first-predictions.json`, `first-report.json`, `reserve-freeze.json`이 재진입 지점이다. 보고서만 Git에 남긴다.

로컬 모델을 실행하거나 다운로드하지 않았다. 로컬에서는 HTML 요청·파싱·해시 계산과 기존 JavaScript 검사기의 단발 비교를 수행했다. 측정된 초기화는 758ms, 151개 검사는 220ms였고, 종료 시점 프로세스 RSS는 약 366MiB였다. 이는 최고 메모리 사용량이나 전체 수집 과정의 자원 측정값은 아니다. 전체 빌드·UI·E2E 검사는 이번 수집 범위에서 실행하지 않았다.

이미지·영상·첨부파일은 수집하지 않았다. 차단·robots 제한이 있는 출처는 우회하지 않았다. NBA매니아는 429로 중단했고, 82쿡의 추가 예비 표본 요청은 연결 거부로 실패했다. 이 실패를 정상 표본으로 세지 않는다.
