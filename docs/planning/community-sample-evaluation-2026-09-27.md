# 공개 커뮤니티 표본의 첫 비교

현재 검사기는 이 표본에서도 필수 수정 누락과 정상 인명·약어의 오교정을 보인다. 확정한 필수 수정 전체를 첫 후보에서 제공한 표본은 한국어 5/10개, 영어 0/3개다. 원격 `gpt-6-luna`로 수집과 1차 판정을 수행하고, 검사기 예측 전에 원문 정합성과 판정 오류를 검토했다. 모델 판정의 잠정 평가이며 전문가 확정 정답이나 최종 품질 통과 증거가 아니다.

## 실제 수집 범위

한국어 출처 순서는 [와플보드 2026년 9월 순위](https://waffleboard.io/ranking)를 사용했다. 상위 10개 중 공개 목록을 확보한 디시인사이드와 인벤에서 각 10개를 뽑았다. 목표 40개 중 20개를 확보했고, 다른 사이트의 접근 오류와 robots 제한을 기록했다. 디시 목록은 인기 글, 인벤 목록은 일반 글과 인기·공지 모듈이 섞여 있다.

영어는 [Similarweb의 2026년 8월 전체 웹 순위](https://www.similarweb.com/blog/research/market-research/most-visited-websites/)에서 방문 규모를 확인한 Reddit을 사용했다. AskReddit, CasualConversation, gaming, relationships에서 각 10개를 뽑았다. 이 네 하위 커뮤니티를 영어권 순위 상위 4개라고 주장하지 않는다. 목록 스냅샷은 6일~3주 전 자료였고, 일부 링크를 해석하지 못해 후보 집합이 불완전하다.

| 언어 | 후보 URL | 추첨 표본 | 본문 발췌 | 제목 |
| --- | ---: | ---: | ---: | ---: |
| 한국어 | 디시 34 + 인벤 63 | 20 | 15 | 5 |
| 영어 | 19 + 24 + 25 + 11 | 40 | 17 | 23 |

시드 `wonboard-community-20260927-v1`과 각 URL을 개행으로 연결해 SHA256을 구하고, 커뮤니티별 해시 오름차순 상위 10개를 선택했다. 본문은 첫 25어절 이하의 연속 발췌이며, 본문을 읽을 수 없는 경우 같은 글의 제목을 사용했다. 이미지·영상 중심 글의 자동 관련 링크, 시리즈 안내, 문자 없는 본문을 언어 표본으로 잘못 추출한 경우에는 같은 URL 안에서 추출을 바로잡았다. 목록에 본문이 같이 표시되거나 URL 해석 중 본문이 먼저 보이는 경우도 있었지만 오류 유무로 후보를 골라 넣거나 교체하지 않았다.

이는 확보된 공개 목록 안의 재현 가능한 추첨이다. 모든 사용자·글·시간대의 확률 표본, 방문량으로 가중한 표본, 인터넷 전체의 정확도 측정은 아니다. 원문은 Git 제외 `local-corpora/random-community-2026-09-27/`에 보관한다.

## 예측과 결과

검사 코드 기준은 `6bc1d3d567b98e7b0ac9af49e5acd18c79755bc7`이며, 관련 코드와 어휘 자료의 SHA256을 별도로 고정했다. 기본 사용자 사전이 빈 상태의 공통 JavaScript 검사기를 한 번 실행했다. 원문·1차 라벨·예측 전 검토본·첫 예측·첫 보고서를 각각 보존했다.

| 항목 | 한국어 | 영어 |
| --- | ---: | ---: |
| 확정 오류 표본 | 10 | 3 |
| 필수 수정 전체를 첫 후보로 제공 | 5/10 | 0/3 |
| 필수 수정 전체를 상위 3후보로 제공 | 5/10 | 1/3 |
| 확정 정상 표본 | 8 | 32 |
| 정상문에 실제로 잘못된 수정안을 제시 | 1/8 | 1/32 |
| 정상문의 허용 표기를 다른 허용 표기로 바꾸도록 제안 | 1/8 | 0/32 |
| 판정·추출 문제로 전체 정답 보류 | 2 | 5 |
| 미등록 알림 총수 | 56 | 11 |

‘필수 수정 전체 제공’은 정답에 해당하는 제안만 골랐을 때 발췌문의 확정 수정들을 만들 수 있는지를 뜻한다. 아무 제안이나 모두 적용해도 안전하다는 뜻은 아니다. 이번 확정 오류 표본의 첫 후보 전체 적용 성공 수도 각각 5개와 0개였다. 미등록 알림은 오교정으로 합산하지 않았다. 미등록 대상 주석의 완전성은 검증하지 않아 전체 미등록 회수율을 주장하지 않는다.

영어에서는 `jaust`의 후보가 `jaunt`, `joust`, `just` 순이었고, `its 5am`과 복수 주어의 `doesn’t`를 놓쳤다. 한국어에서는 짧은 띄어쓰기 누락을 미등록 안내로만 처리하거나 아무 수정도 제공하지 않은 항목이 있다. 한국어 게시글 속 영문 인명 `clara galle`와 영어 약어 `pls`에는 다른 단어로 바꾸는 잘못된 후보가 나왔다.

로컬 모델은 실행하거나 다운로드하지 않았다. 기존 검사기의 단발 실행은 초기화 약 768ms, 60개 검사 약 87ms였다. 종료 시 프로세스 RSS는 약 355MiB였다. 이 짧은 발췌문 측정은 브라우저·Electron UI나 긴 글 성능 검증을 대신하지 않는다. 전체 빌드·E2E는 재실행하지 않았다.

## Luna 판정과 사후 집계 정정

Luna의 1차 판정에는 발췌문에 없는 단어를 수정 대상으로 쓴 항목, 명백한 축약 철자나 띄어쓰기를 놓친 항목, 원문 보존용 메타데이터 형식 오류가 있었다. 영어의 가사 본문과 제목 판정을 혼동한 항목도 있었다. 예측 전에 별도 파일에서 정리했고 원래 라벨은 덮어쓰지 않았다. 일부 표현의 규범 판정이나 HTML 문단 경계가 불확실한 항목은 보류했다. Luna를 수집·초벌 판정에 사용할 수 있지만, 이번 실행은 그 출력을 검증 없이 정답으로 쓰면 안 된다는 근거도 남겼다.

첫 자동 집계는 한국어 정상문 오교정을 2/8개로 셌다. 그러나 그중 `300만원 → 300만 원`은 허용 표기 사이의 변경이다. 예측 전 확인한 [국립국어원의 숫자·단위 붙임 허용 설명](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=331839)을 라벨의 허용 정답 목록에 함께 열거하지 않은 오류였다. **예측 후 정정**임을 `scoring-errata.json`에 남기고, 같은 첫 예측으로 실제 오교정 1/8개와 불필요한 허용형 변경 1/8개를 분리했다. 원본 2/8 보고서도 보존했다. 검사기나 예측을 다시 실행해 결과를 바꾸지 않았다.

수집과 첫 비교는 수행했지만, 작은 표본과 모델 판정의 한계가 남는다. 특히 영어 오류는 3개뿐이므로 일반적인 영어 오류 회수율을 추정할 수 없다. 다음 개선의 근거는 이름·약어 보존, 수정 없이 미등록으로만 남기는 한국어 구간, 영어 문맥과 후보 순위다. 이 자료는 이제 노출된 개발 자료이며 이후 수정의 독립 평가 자료로 다시 사용할 수 없다.

## 재현 파일

- `protocol.json`, `source-basis.json`, `*-frame.json`, `*-access.json`: 출처, 시드, 후보 집합, 접근·추출 한계.
- `*-samples.json`, `*-labels.json`: 원문과 Luna 원판정.
- `adjudicated-input.json`, `adjudication-notes.json`, `input-freeze.json`: 예측 전 검토와 해시.
- `first-predictions.json`, `first-report.json`: 단 한 번의 최초 검사 결과.
- `audited-report.json`, `scoring-errata.json`: 같은 예측의 허용 표기 집계 정정.
- `run.mjs`, `adjudicate.py`: 로컬 단발 비교와 예측 전 정합성 검토. 기존 최초 결과 파일이 있으면 덮어쓰지 않고 실패한다.
