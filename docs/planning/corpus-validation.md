# 로컬 말뭉치 검증기

원자료는 `local-corpora/nikl`에 보관하며 전체 `local-corpora/`는 Git 비추적이다. 약정서와 원문을 배포 자산에 넣거나 AI 대화에 붙여 넣지 않는다. 복사는 이용 권한을 변경하지 않으며 승인 목적·이용 기간 조건은 그대로 적용된다.

Vite 개발 서버는 이 폴더를 감시하거나 HTTP로 제공하지 않는다. 기존 비밀 파일 차단 목록을 유지하면서 추가로 차단한다. 코드에서 이 폴더를 import하지 않으며, 앱 번들의 public 폴더와도 분리한다. 다른 호스팅 도구로 소스 전체를 업로드할 때도 반드시 이 폴더를 제외해야 한다.

## 원문 표본 검사

```sh
node scripts/validate-corpus.mjs --documents 100 --split development --field original_form --output baseline-development.json
```

JSON 파일 전체의 구조·누락·중복을 확인한 뒤 말뭉치별 최대 100개 대화를 결정론적으로 선택한다. 각 대화의 발화를 모두 검사한다. 동일 내용의 대화는 같은 분할로 배정하고 자료 내 중복을 제외한다. 80/20 해시 분할이며 `holdout`은 구현을 고정한 최종 시험까지 남긴다. 날짜나 앞쪽 파일 순서로 표본을 고르지 않는다.

`form`과 `original_form`의 차이는 집계하지만 교정 정답으로 가정하지 않는다. 이 모드의 결과는 제안 발생률·미등록 안내 발생률과 성능이다. **정확도·오탐률·미등록 표현 재현율은 정답 주석이 없으므로 null이다.** 자주 검출됐다는 이유만으로 오류이거나 정상이라고 판정하지 않는다. 구조 오류나 중복 ID가 있으면 해당 자료의 검사 실행을 보류하고 종료 코드 2를 반환한다. 예외 내용과 원문은 출력하지 않는다.

결과는 `local-corpora/reports/`에 새 파일로 저장하며 기존 결과를 덮어쓰지 않는다. 코드·데이터 해시와 입력 전체 해시, 표본 선택 해시로 재현성을 확인한다. 원자료와 검사기 모두 바뀌지 않아야 비교가 가능하다. 실행 시간은 환경에 따라 달라진다. 현재 두 자료는 한국어 대화 자료이며 영어 전체 품질을 대표하지 않는다.

## 사람이 판정한 정답 검사

`local-corpora/labels.json`에 완전하게 판정한 사례를 준비한다. 원문과 정답은 이 비공개 로컬 파일에만 둔다. 다음은 말뭉치에서 인용하지 않은 구조 설명용 합성 예다.

```json
{"cases":[{"text":"ㅋㅋ","complete":true,"expected":[{"from":0,"to":2,"type":"unknown"}]}]}
```

```sh
node scripts/validate-corpus.mjs --labels labels.json --output adjudicated.json
```

범위는 UTF-16이며 앞에서부터 겹치지 않게 작성한다. `spelling`·`spacing`에는 해당 범위의 정답 문자열 `suggestions` 배열이 필요하다. `unknown`은 수정 정답을 강제하지 않는다. 정상 사례는 `expected: []`이다. `complete: true`는 문장의 검토 대상 전체를 판정했다는 선언이며, 부분 주석을 완전한 정답처럼 평가하지 않는다.

철자·띄어쓰기 검출과 상위3 후보, 미등록 안내 검출/누락, 예상하지 않은 미등록 안내, 잘못된 교체 후보를 각각 집계한다. 범위가 다르면 자동 정답으로 간주하지 않는다. 의도적 인터넷 표현은 무조건 정상으로 두지 않고 미등록 대상으로 주석화한다. 명확한 표기 오류는 오류로 주석화한다. 조사·동사와 약칭의 중의성은 사람이 판정한다.

사례마다 선택적으로 `personal: ["질게"]`를 지정하면 해당 사용자 사전 상태로 검사한다. 실제 사용자 사전을 읽거나 변경하지 않는다. 등록 전·후·삭제 후 사례를 따로 넣어 미등록 안내만 사라지고 주변 띄어쓰기 제안은 유지되는지 검증한다. `missed`는 유형별 기대 검출 수에서 실제 검출 수를 뺀 값이다. 직접 작성한 회귀 사례의 통과율을 독립적인 언어 정확도로 표시하지 않는다.

검증: `node --test tests/unit/corpus-validator.test.mjs`. 합성 자료만 사용하며 원문을 테스트나 공개 저장소에 넣지 않는다. 이 검증기는 모델 학습·어휘 채택·자동 교정을 하지 않는다.
