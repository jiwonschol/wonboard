# 맞춤법 실전 평가 중단 및 재개 위치

지원의 이동 요청에 따라 r59 평가 도중 안전하게 중단했다. 목표는 미달성 상태이며 자동으로 다음 회차를 시작하지 않는다. 제품 코드는 `d83be35`로 고정돼 있다. 이 체크포인트 커밋은 제품 동작을 바꾸지 않는다.

## 저장 상태

- r59는 2,278개 URL 요청을 완료했고 2,130개 글을 확보했다. 그중 2,037개 글의 주석 검토·최초 예측·제안 판정을 완료했다. 일반 글은 1,980개이며 첫 교정 제안 278개 중 명백한 오교정은 11개(3.96%)다.
- 한국어 166개 제안 중 5개(3.01%), 영어 112개 중 6개(5.36%)다. A 묶음 136개 중 7개(5.15%), B 묶음 142개 중 4개(2.82%)다. 영어와 A 묶음이 기준을 넘고, 남은 93개 글도 평가 전이므로 통과로 해석하면 안 된다.
- 필수 교정 도달은 한국어 기준 135 → 후보 136, 영어 기준 62 → 후보 83이다. 동일 구간의 손실·증가 내역은 `partial-results.json`에 있다. 전체 인터넷의 대표 표본이나 전문가 정답은 아니다.
- 제품 스냅샷 14개 파일의 해시는 r59 동결 기록과 모두 일치한다. 이번 종료 시 데이터 정책 검사와 두 미적용 패치의 적용 가능성 검사가 통과했다.
- `r60-ko-unapplied.patch`, `r60-en-unapplied.patch`는 다음 회차용 **미적용 초안**이다. 각각 별도 복사본에서 한국어 테스트 158개, 영어 테스트 75개를 통과했지만 두 패치를 통합한 전체 노출 자료 재검증과 새 평가를 아직 하지 않았다. 현재 제품에 적용된 것으로 보고하지 않는다.

## 재개 순서

모든 아래 상대 경로의 기준 디렉터리는 `local-corpora/historical-goal-2026-09-27/`이다. 원문·주석·최초 예측은 저장소의 기존 데이터 정책대로 Git에서 제외하고 로컬에 보존했다. **Git 커밋만 다른 기기에 가져오면 원본 평가 자료는 따라오지 않는다.** 같은 작업 폴더에서 재개하거나 이 디렉터리도 별도로 보존해야 한다. 사용자 파일 `docs/.DS_Store`는 수정·커밋하지 않았다.

1. `candidate-r59-freeze.json`의 제품 해시와 `r59-paused-partial-gates.json`을 확인한다. 이미 평가한 47개 `evaluation-r59-*` 묶음의 최초 예측을 덮어쓰거나 재실행하지 않는다.
2. `labels/en-r59-mse/mse-labels-0950.json`은 담당자가 50행·중복 없음·검증 오류 없음으로 발행 완료했다. 아직 부모 검토와 평가를 하지 않았다. `collection/en/mse-r59-reserve/checkpoint-0950.json`과 함께 `stage-fresh.mjs r59 mse-19`로 준비하고, 원문·골드 전수 검토를 끝낸 뒤에만 최초 예측과 제안 판정을 실행한다.
3. 마지막 43행은 `collection/en/mse-r59-reserve/samples.json`의 인덱스 950–992다. 담당자가 원문만 봤으며 주석은 작성하지 않았다. 첫 ID는 `mse-6649309`, 예정 주석 파일은 `labels/en-r59-mse/mse-labels-1000.json`이다. 주석 완료 통지를 받은 뒤 `mse-20`으로 준비한다. 원문을 새 미노출 자료로 다시 세지 않는다.
4. 나머지 93행의 평가가 끝나면 `parent-r59-scripts/finalize-r59-coverage.py`, `aggregate-r59-gates.mjs`, `parent-r59-scripts/write-r59-report.py`를 사용해 전체 2,130행의 커버리지와 최종 결과를 확정한다. 집계에는 기존 판정 정정 sidecar를 반영하는 r59 집계기를 사용한다.
5. r59 최종 확정 후에만 두 r60 초안을 검토·통합한다. 기존 노출 자료 23,192행의 변경 제안을 확인하고 새 오교정·유효 교정 손실·필수 교정 도달을 검증한다. 관련 테스트와 타입 검사·데이터 정책을 통과한 다음 새 코드를 커밋·동결한다.
6. r60 본문은 아직 수집하지 않았다. `collection/r60-metadata/hn-mid2025-frame/`는 2025년 6–8월의 완료된 3,573개 후보 목록이다. 한국어 목록의 완료 여부는 옆의 중단 기록을 확인하고, 부분 목록을 최종 목록으로 취급하지 않는다. 메타데이터 프레임·추첨·코드를 모두 고정한 뒤에만 새 본문을 요청한다.

r59 한국어 목록이 수집 담당자의 최종 통지 전에 선택된 경위는 `collection/r59-metadata/selection-frame-provenance-amendment.json`에 보존돼 있다. 최종 목록에서 빠진 3개는 원래 날짜 조건으로 이미 제외됐으며 선택 URL·순서는 바뀌지 않았다. 원래 선택 해시를 고쳐 쓰지 않는다.

부모 검토·실행 도우미는 `parent-r59-scripts/`에 복사해 임시 폴더에만 의존하지 않도록 보존했다. 영어 초안 생성기를 다시 실행하면 덧붙인 테스트가 사라질 수 있으므로 이 커밋의 완성된 패치를 기준으로 사용한다.
