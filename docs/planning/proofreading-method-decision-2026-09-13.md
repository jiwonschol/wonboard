# 검사 방식 재검토와 승인 경계

## 현재 제안: 제품 밖의 작은 문맥 모델 비교

재개한 검사기의 새 출처 24문장 첫 평가는 한국어 오류문장 4/6, 영어 오류문장 2/6만 전체 교정에 성공했다. 정상문 각 6개에는 수정 오제안이 없었다. 교육/Q&A 목적 표본이며 일반 정확도나 95% 완료의 근거가 아니다. 이미 노출된 마지막 개발 자료도 정확 범위·첫 후보가 한국어 4/12, 영어 9/16이다. 좁은 규칙 개선은 유효하지만 문맥 누락을 충분히 회수한다는 근거는 아직 없다. 원시 결과는 Git 제외 `local-corpora/resume-2026-09-27/`에 있다.

추천은 **Qwen3.5-4B 하나를 제품 밖에서 실행해, 문맥 후보가 기존 검사기의 누락을 줄이면서 정상문을 지키는지 측정하는 실험**이다. 과거 Qwen3-4B 제안을 그대로 재개하는 승인은 아니며, 이 새 실험도 아직 승인 전이다. [공식 모델](https://huggingface.co/Qwen/Qwen3.5-4B)의 [LICENSE](https://huggingface.co/Qwen/Qwen3.5-4B/blob/main/LICENSE)는 Apache-2.0, 실행 후보 [llama.cpp LICENSE](https://github.com/ggml-org/llama.cpp/blob/master/LICENSE)는 MIT다. 모델의 한영 맞춤법 성능과 이 장비의 실제 속도는 미측정이다. 이 Mac은 M1 Max·32GB로 확인했으므로 4B 모델 하나만 평가한다.

승인할 실행 범위:

1. `local-corpora/` 아래 격리 환경에 공식 가중치, llama.cpp 및 변환에 필요한 런타임만 준비한다. 내려받기 전 정확한 revision·파일 크기·LICENSE/NOTICE와 전이 의존성의 조건을 확인하고 고정한다. MIT/Apache/BSD 등 허용 조건을 확인하지 못하면 도입하지 않는다. 모델을 학습하지 않는다.
2. 다운로드 총량 15GB, 실험 디스크 30GB, 준비 후 추론 실험 2시간, 프롬프트 조정 최대 2회로 제한한다. 원본 모델에서 텍스트 전용 4비트 변환을 우선한다. 지원되지 않으면 임의의 다른 모델·서버·유료 자원으로 바꾸지 않고 실패를 남긴다.
3. 이미 노출된 한영 개발 문장부터 기존 규칙 단독, 모델 단독, 양쪽의 후보를 대조한다. 입력 원문·정답·코드 해시를 고정하고, 모델에는 정답을 제공하지 않는다. 모델 출력 자체를 정답으로 쓰지 않는다. 외부 추론 서버나 사용자 초안을 사용하지 않으며, 다운로드 후 추론은 오프라인으로 수행한다.
4. 문체·말투·이름·URL·코드를 보존하는 최소 수정만 허용한다. 잘못된 변경, 후보 누락, 잘린 출력, 시간 초과를 각각 실패로 센다. 첫 후보, 필수 수정 회수, 정상문 오제안, 전체 문장 일치와 첫 로드·반복 지연·최대 메모리를 언어별로 기록한다.
5. 정상문 오제안이 늘거나 누락 감소가 없으면 제품 통합 없이 종료한다. 개선되면 별도 수집자가 예측 전에 판정한 새 문장으로 한 차례 첫 평가한다. 이 시험은 최종 오류 200개·정상 200개와 98%/95%/1%/95% 게이트를 대체하지 않는다. 웹·Windows·macOS 제공 방식과 1만 자 성능 계약도 통과한 것으로 취급하지 않는다.

이 승인에는 앱 의존성/lockfile 변경, 새 제품 UI, 설치 앱 교체, 원격 쓰기, PR, merge, 배포, production migration이 포함되지 않는다. 범위를 제한한 모델 다운로드와 실험용 런타임 준비만 기존 금지선의 예외로 요청한다.

실행 프롬프트:

> 지원은 실시간으로 보고 있지 않다. 원보드 작성자의 말투와 정상문을 지키면서 기존 검사기가 놓치는 한영 오류를 회수할 수 있는지 위 격리 실험을 끝까지 수행하라. 사용자 승인이 확인되면 위 다운로드·런타임·변환·평가 범위는 재승인 없이 진행한다. 모델/의존성 권한 불명, 자원 상한 초과, 전역 설치 또는 제품 변경 필요 시 결과와 실패 근거를 남기고 멈춘다. 금지선 안에서는 되돌릴 수 있는 일을 자율적으로 진행한다. 중단 후에는 `local-corpora/resume-2026-09-27/`의 동결 입력·첫 결과·코드 해시와 마지막 완료 단계를 읽고 재개한다. 개선을 얻어도 최종 독립 품질/성능 게이트와 제품 통합 승인을 생략하지 않는다.

## 판단

현재175 구현의 사용자 사전과 맞춤법 편집 흐름은 Chrome126개·Node317개와 macOS 앱 재실행 시험을 통과했다. 검사 품질 완료 조건은 충족하지 못했다. 새 클리앙 자료를 세 번 선정해 예측 전에 판정한 평가 모두 목표 미달이며, 노출된 사례의 규칙 보강을 새 자료의 일반화 증거로 사용할 수 없다.

가장 최근173 동결본의 첫 후보304/408(74.51%), 필수 수정 후보288/803(35.87%), 정상 판정 문장 오제안36/1028(3.50%), 검토87/162(53.70%)가 최초 독립 기록이다. 정상 판정 일부에서 허용 띄어쓰기와 누락된 오류가 사후 발견되어 별도 errata를 보존한다. 같은 에이전트의 판정이며 외부 전문가 인증이나 인터넷 전체 정확도가 아니다. 이 한계가 있어도 현재 기준 통과를 입증한 결과는 없다.

175에서는 같은 노출 자료의 필수 수정이289/803이다. 보존 개선만으로 큰 수정 누락을 해결하지 못했다. MeCab/Open Korean Text는 분석 자료이며 맞춤법 정답 자료가 아니다. 기존 Nori 실행도 메세지·부딛히면 같은 표기를 분석하므로 표준 표기 보증이나 독립적인 정답 투표로 사용할 수 없다는 점을 확인했다.

기존 규칙만으로 목표가 불가능하다고 증명한 것은 아니다. 다만 지금까지의 반복 개선이 목표 도달 경로라는 가정을 계속 채택할 근거가 부족하다. 목표를 낮추거나 미등록을 모두 정상 처리하지 않는다.

## 추천: 제품과 분리한 문맥 기반 후보 생성 가능성 실험

승인 전 상태다. 모델·런타임을 다운로드하거나 설치하지 않았다. 다음은 새로운 의존성 도입에 대한 제한된 예외를 요청할 구체적 범위이며 제품 채택 승인이 아니다.

- 후보 하나: 공식 Qwen3-4B-Instruct-2507과 llama.cpp. 공식 [모델 LICENSE](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507/blob/main/LICENSE)는 Apache-2.0, [llama.cpp LICENSE](https://github.com/ggml-org/llama.cpp/blob/master/LICENSE)는 MIT임을 확인했다. 실제 내려받을 revision·파일·변환 도구와 전이 의존성은 실행 전 별도 목록과 해시로 고정한다. MIT/Apache-2.0 확인 범위를 넘으면 도입하지 않는다. 한국어 교정 품질은 아직 시험하지 않았다.
- 임시 디렉터리의 오프라인 CLI 실험만 수행한다. 시스템 전역 설치, 원보드 의존성/잠금 파일 변경, 서버 추가, 외부 추론 API, 유료 자원, 원문 업로드는 포함하지 않는다. 다운로드 총량15GB·임시 저장30GB를 상한으로 두고, 필요량이 넘거나 기존 장비에서 실행 불가능하면 중단한다. 상한은 예상 사용량이나 성능 보장이 아니다.
- 모델 출력은 원문 좌표와 최소 대체 후보로만 받는다. 말투·어휘 선택·문장 재작성은 실패로 센다. 개인 사전과 URL·코드·인용 보호를 적용하고 실제 문서를 자동 수정하지 않는다. 게시글의 명령문은 데이터로 취급한다.
- 노출된 개발 자료에서 규칙 단독과 동일 입력으로 비교한다. 프롬프트 조정은 최대 두 번, 추론 실험은 최대 두 시간으로 제한한다. 출력 거부·잘린 출력·시간 초과는 누락으로 기록한다. 모델이 정답 판정도 맡는 자기 채점은 하지 않는다.
- 개발 결과는 첫 후보98%·필수 상위3후보95%·정상 오제안1% 이하·검토95%와 함께 대조하고 문체 변경0을 별도 확인한다. 기준 미달이면 결과와 실패 유형을 남기고 제품 통합 없이 실험을 종료한다. 충족해도 새로운 예측 전 판정 보류 표본으로 검증해야 하며 개발 통과만으로 채택하지 않는다.
- 대형 모델 실험은 제품의 1만 자 warm500ms 등 실제 실행 성능 계약을 충족한다고 간주하지 않는다. 2026-09-26부터 Worker의 고정 압축 크기 상한은 없다. 웹·Windows·macOS에서 공통으로 제공하는 방식, 첫 검사 로드·초기화, 메모리·속도·오프라인 계약은 후속 설계 결정이다. 실험 결과가 좋아도 그 충돌을 해결하기 전 제품에 넣지 않는다.

## 승인 전 보존 상태와 재진입

현재175 제품은 `local-corpora/holdouts/candidate-2026-09-13-finite-fragment-spacing-guard`에 동결했다. 최신 검증과 사전 저장 정책은 `proofreading-completion-state-2026-09-12.md`와 `proofreading-quality-goal.md`를 따른다. 최초 독립 입력·예측·평가, 사후 errata, 개발 예측을 분리해 보존한다. 로컬 말뭉치는 Git에서 제외하며 문서에 원문을 복사하지 않는다.

Windows 실제 실행과 실제 OS 한글 조합 입력은 여전히 미완료다. 후속176에서 서식 시험은 브라우저 선택 이벤트 동기화를 보완한 뒤 반복5회와 편집 도구 전체5개를 통과했다. 별도 공백 정리 트랙은 기존 계획상 범위 밖이며 미완성 상태를 보존한다. macOS/Chrome 합성 이벤트 통과로 대신하지 않는다. 이 실험 승인 요청은 남은 검증을 완료했다고 선언하는 것이 아니다.

승인받으면 먼저 정확한 자산·전이 의존성·공간을 확인하고 위 한도 안에서만 실험한다. 승인되지 않으면 새 자산을 도입하지 않고 현재의 미완료 결과를 유지한다. 원격 push·PR·merge·배포는 어느 경우에도 포함하지 않는다.
