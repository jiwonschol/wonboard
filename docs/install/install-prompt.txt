원보드(Wonboard)를 내 ChatGPT Sites에 설치해 주세요. 이 요청은 이미 있는 프로젝트를 Sites로 배포하는 웹사이트(website) 작업입니다.

원보드는 글과 사진을 쓰고 보관하는 오픈소스 글쓰기 도구입니다. 새 사이트를 만들어 달라는 요청이 아닙니다. 아래 저장소의 코드를 그대로 가져와 배포해 주세요. 화면과 기능을 새로 만들거나 고치지 마세요.

저장소: https://github.com/jiwonschol/wonboard (태그 v0.1.0-beta.2)

아래 순서대로 진행하고, 한 단계가 끝날 때마다 무엇을 했는지 한국어로 짧게 알려 주세요. 막히면 추측으로 넘어가지 말고, 어느 단계에서 왜 막혔는지 그대로 알려 주세요.

시작 전 확인
이 작업에는 저장소를 가져오고 명령을 실행하는 도구가 필요합니다. 지금 대화에서 저장소를 가져오거나 명령을 실행할 수 없다면 ZIP 파일을 달라고 하지 말고 여기서 멈춘 뒤, 저에게 다음과 같이 안내해 주세요.
- ChatGPT 화면 위쪽 가운데의 「Chat | Work」에서 Work를 고르고, 새 대화에 이 설치 문장을 다시 붙여넣어 주세요. 입력창에 「ChatGPT로 Work 시작」이 보이면 Work입니다.
- ChatGPT Plus·Pro·Business·Enterprise·Edu 중 하나의 유료 요금제 계정이어야 합니다.

1. 코드 가져오기
위 저장소에서 태그 v0.1.0-beta.2의 코드를 가져옵니다. main 브랜치나 다른 태그의 코드를 쓰지 마세요. 명령은 실행되는데 GitHub에서 저장소를 받지 못할 때만 여기서 멈추고, 제가 https://github.com/jiwonschol/wonboard/archive/refs/tags/v0.1.0-beta.2.zip 파일을 내려받아 이 대화에 첨부하도록 안내해 주세요.

2. 빌드
Node.js 22.13 이상과 pnpm 11.19.0을 씁니다. `pnpm install --frozen-lockfile`을 실행한 다음 `pnpm build:sites`를 실행합니다. 성공하면 화면 파일이 `dist/client`에, 서버 파일이 `dist/server/index.js`에 생깁니다.

3. Sites로 배포할 준비
저장소에 있는 설정 그대로 배포해 주세요. 배포 설정이나 DB 스키마를 새로 만들거나 코드를 고치지 마세요.
- 공식 Sites 연결은 `vite.sites-worker.config.ts`의 `@openai/sites-vite-plugin`이 빌드할 때 적용합니다. 서버 코드는 `apps/server/src/sites/worker.ts`이고, 기본 내보내기가 fetch 처리기입니다.
- `.openai/hosting.json`에 선언된 D1 `DB`, R2 `MEDIA`를 그대로 연결합니다. Sites가 새 프로젝트를 연결하면서 넣는 프로젝트 ID만 설치마다 달라집니다.
- `wrangler.json`의 `ASSETS` 선언대로 `dist/client`를 제공합니다. 배포 꾸러미에는 `dist/server/index.js`와 `dist/.openai/hosting.json`, `dist/.openai/drizzle`이 함께 있어야 합니다.
- 새 DB는 빌드에 포함된 `drizzle`의 초기 마이그레이션을 그대로 적용합니다. `apps/server/src/sites/schema.sql`은 로컬 검증용입니다. `apps/server/src/sites/migrations`의 기존 설치 업그레이드 SQL은 새 DB에 중복 적용하지 않습니다.
- `apps`와 `packages`의 화면과 저장 동작을 바꾸지 마세요. 그대로 배포할 수 없다면 설정을 즉석에서 바꾸지 말고 오류를 알려 주세요.

4. 배포
버전을 저장하고 배포합니다. 사이트 접근 범위는 새 사이트의 처음 상태(소유자와 워크스페이스 관리자만 접근) 그대로 두고, 제가 따로 요청하기 전에는 범위를 넓히거나 공개로 바꾸지 마세요. 이 사이트에는 아직 원보드의 소유자가 없어서, 범위를 넓히면 먼저 로그인한 아무나 소유자가 됩니다. 배포가 끝나면 사이트 주소를 알려 주세요.

5. 로그인 안내
새 사이트에서는 처음 로그인한 계정이 원보드의 소유자로 기록됩니다. 배포가 끝나면 저에게 다음과 같이 안내해 주세요.
- 배포가 끝나고 열리는 사이트 미리보기 창에 “시작 전에 확인해주세요.” 안내가 보이면 제 계정이 소유자로 기록된 것입니다. 안내를 읽고 확인란에 표시한 뒤 “내 글쓰기 공간 열기”를 누르면 설치가 끝납니다.
- 미리보기 창이 없으면 사이트 주소를 다른 사람에게 알리기 전에 제가 바로 새 탭에서 엽니다. 「접속하려면 로그인하세요」 화면에서 「ChatGPT로 계속」을 누르고, 계정 목록에서 이 사이트를 만든 계정을 이름으로 골라 로그인합니다. 목록의 순서는 바뀔 수 있습니다.
- 계정을 고른 뒤 「세션이 종료되었습니다」가 나오면 사이트 주소를 다시 엽니다.
- 원보드 화면에 “이 사이트에는 아직 소유자가 없어요.”가 보이면 “ChatGPT로 로그인”을 누릅니다.
소유자를 정하려고 환경 값을 만들거나 코드를 고치지 마세요. 제가 사이트를 여는 것으로 충분하고, 연결 ID를 물어보지 않아도 됩니다.

6. 소유자가 잘못 정해졌을 때만
제가 “다른 계정의 글쓰기 공간입니다.”라는 안내가 보인다고 알리면, 다른 계정이 먼저 로그인해 소유자가 된 것입니다. 그때만 다음과 같이 안내해 주세요.
- 그 화면의 “계정 연결 정보”를 펼치고 “연결 정보 확인”을 누르면 연결 ID가 나옵니다.
- 그 연결 ID를 복사해 이 대화에 붙여넣습니다.
제가 연결 ID를 붙여넣으면 그 값을 이 사이트의 환경 값 `WONBOARD_OWNER_ID`로 저장하고, 4단계에서 저장한 버전을 그대로 다시 배포해 주세요. 환경 값은 다시 배포해야 적용되고, 이 값이 있으면 기록된 소유자보다 우선합니다. 값은 제가 붙여넣은 그대로 쓰고, 이름이나 이메일을 대신 넣지 마세요. 이 값을 코드나 `.openai/hosting.json` 같은 프로젝트 파일에 적지 마세요. 직접 저장할 수 없으면, 제가 Sites의 사이트 설정에서 `WONBOARD_OWNER_ID`를 직접 넣도록 안내해 주세요.

5단계 안내를 할 때 사이트 주소, 접근 범위, 배포한 버전과 그 버전을 만든 원보드 태그를 함께 정리해서 알려 주세요.
