원보드(Wonboard)를 내 ChatGPT Sites에 설치해 주세요. 이 요청은 이미 있는 프로젝트를 Sites로 배포하는 웹사이트(website) 작업입니다.

원보드는 글과 사진을 쓰고 보관하는 오픈소스 글쓰기 도구입니다. 새 사이트를 만들어 달라는 요청이 아닙니다. 아래 저장소의 코드를 그대로 가져와 배포해 주세요. 화면과 기능을 새로 만들거나 고치지 마세요.

저장소: https://github.com/jiwonschol/wonboard (main 브랜치)

아래 순서대로 진행하고, 한 단계가 끝날 때마다 무엇을 했는지 한국어로 짧게 알려 주세요. 막히면 추측으로 넘어가지 말고, 어느 단계에서 왜 막혔는지 그대로 알려 주세요.

1. 코드 가져오기
위 저장소의 main 브랜치 코드를 가져옵니다. 저장소를 직접 가져올 수 없으면 여기서 멈추고, 제가 https://github.com/jiwonschol/wonboard/archive/refs/heads/main.zip 파일을 내려받아 이 대화에 첨부하도록 안내해 주세요.

2. 빌드
Node.js 22.12 이상과 pnpm 11.19.0을 씁니다. `pnpm install`을 실행한 다음 `pnpm build:sites`를 실행합니다. 성공하면 화면 파일이 `dist/client`에, 서버 파일이 `dist/server/index.js`에 생깁니다.

3. Sites로 배포할 준비
이 프로젝트를 Sites로 배포할 수 있는지 확인하고, 배포에 필요한 변경만 해 주세요.
- 서버 코드는 `apps/server/src/sites/worker.ts`이고, 기본 내보내기가 fetch 처리기입니다.
- 글을 담는 D1 데이터베이스를 `DB`라는 이름으로, 사진과 파일을 담는 R2 저장소를 `MEDIA`라는 이름으로 연결합니다.
- 화면 파일은 `dist/client`를 그대로 제공합니다. 서버 코드는 `ASSETS`라는 이름의 정적 파일 연결이 있으면 그것을 씁니다.
- 새 데이터베이스의 표는 `apps/server/src/sites/schema.sql`에 적힌 그대로 만듭니다. `apps/server/src/sites/migrations` 폴더는 예전 설치를 올릴 때만 쓰므로 새 설치에는 적용하지 않습니다.
- `apps`와 `packages` 폴더 안의 화면과 저장 동작은 바꾸지 마세요. 꼭 바꿔야 배포할 수 있다면, 바꾸기 전에 무엇을 왜 바꾸는지 먼저 알려 주세요.

4. 배포
버전을 저장하고 배포합니다. 사이트 접근 범위는 새 사이트의 처음 상태(소유자와 워크스페이스 관리자만 접근) 그대로 두고, 제가 따로 요청하기 전에는 범위를 넓히거나 공개로 바꾸지 마세요. 배포가 끝나면 사이트 주소를 알려 주세요.

5. 로그인과 소유자 연결
배포가 끝나면 저에게 다음과 같이 안내해 주세요.
- 사이트 주소를 열면 “원보드 설치가 아직 끝나지 않았어요.”라는 화면이 나옵니다.
- “ChatGPT로 로그인”을 눌러 로그인합니다.
- “계정 연결 정보”를 펼치고 “연결 정보 확인”을 누르면 연결 ID가 나옵니다.
- 그 연결 ID를 복사해 이 대화에 붙여넣습니다.
제가 연결 ID를 붙여넣으면 그 값을 이 사이트의 환경 값 `WONBOARD_OWNER_ID`로 저장해 주세요. 값은 제가 붙여넣은 그대로 쓰고, 이름이나 이메일을 대신 넣지 마세요. 이 값을 코드나 `.openai/hosting.json` 같은 프로젝트 파일에 적지 마세요. 직접 저장할 수 없으면, 제가 Sites의 사이트 설정에서 `WONBOARD_OWNER_ID`를 직접 넣도록 안내해 주세요.

6. 다시 배포
환경 값은 다시 배포해야 적용됩니다. 4단계에서 저장한 버전을 그대로 다시 배포해 주세요.

7. 설치 상태 확인
다시 배포가 끝나면 저에게 사이트로 돌아가 “설치 상태 다시 확인”을 누르라고 안내해 주세요. “시작 전에 확인해주세요.”라는 안내와 “내 글쓰기 공간 열기” 버튼이 보이면 설치가 끝난 것입니다. 여전히 “원보드 설치가 아직 끝나지 않았어요.”가 보이면 환경 값의 이름과 값, 다시 배포가 끝났는지를 확인해 주세요.

마지막에 사이트 주소, 접근 범위, 배포한 버전을 정리해서 알려 주세요.
