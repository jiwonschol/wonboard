# 원보드 설치 안내 (베타)

원보드는 내 ChatGPT 사이트(Sites)에 직접 설치해서 쓰는 글쓰기 도구입니다. 설치는 [설치 문장](./install-prompt.txt)을 내 ChatGPT에 붙여넣는 것으로 시작하고, 그 뒤의 작업은 내 ChatGPT가 합니다. 이 문서는 각 단계에서 무엇을 보게 되는지, 막히면 무엇을 하면 되는지, 그만 쓰려면 어떻게 하는지를 설명합니다.

빠르게 시작하려면 [원보드 소개 페이지](https://jiwonschol.github.io/wonboard/)의 설치 버튼을 누르세요. 설치 문장이 복사되고 ChatGPT가 열립니다.

## 먼저 알아둘 것

**다른 계정에서 확인되지 않음.** 지금까지 실제 설치는 만든 사람의 계정에서 한 번 한 것이 전부입니다. 그때는 저장소 주소를 알려 주는 대신 코드 ZIP 파일을 ChatGPT 작업에 첨부했습니다. 다른 계정에서 이 안내대로 끝까지 설치되는지는 베타 참가자의 첫 설치로 확인할 예정입니다. 중간에 막히면 [문제 알리기](#문제-알리기)로 알려 주세요. 그 내용으로 이 안내를 고칩니다.

원보드는 무료이고 앞으로도 유료로 바꾸지 않습니다. 원보드에는 회원 가입이 없고, 로그인은 ChatGPT 로그인 하나입니다. ChatGPT 요금은 OpenAI에 내는 것이며 원보드와 관계가 없습니다.

## 필요한 것

| 항목 | 내용 |
| --- | --- |
| 요금제 | ChatGPT Plus·Pro·Business·Enterprise·Edu 중 하나. Sites는 이 요금제에서만 쓸 수 있습니다. |
| 지역 | Sites를 쓸 수 있는 지역이어야 합니다. 유럽경제지역(EEA)·스위스·영국에서는 출시 시점에 Sites 사용이나 공개 게시에 제한이 있었습니다. 제한되는 범위(Sites 자체인지 공개 게시만인지)는 요금제에 따라 다를 수 있고, 2026-10-06에는 OpenAI 도움말 페이지가 열리지 않아 정확한 범위를 확인하지 못했습니다. 이 지역에 있다면 내 ChatGPT에 Sites 메뉴가 보이는지로 먼저 확인하세요. 원보드는 공개하지 않은 사이트로 설치되지만, 게시판에 붙일 사진을 남에게 보이려면 공개 게시가 필요합니다. |
| 기기 | ChatGPT 웹(chatgpt.com) 또는 ChatGPT 데스크톱 앱 |

Sites는 공개 베타입니다. 요금제, 지역, 사용 한도는 OpenAI가 바꿀 수 있습니다. 지금 조건은 [Sites 공식 문서](https://learn.chatgpt.com/docs/sites?surface=app)에서 확인하세요.

무료 요금제(Free·Go)에서는 베타 동안 원보드를 쓸 방법이 없습니다. 데스크톱판은 구독자가 보조로 쓰는 용도이고, 베타 동안에는 설치 파일을 배포하지 않습니다.

회사나 학교의 워크스페이스 계정이라면 관리자가 Sites를 꺼 두었을 수 있습니다. 그런 경우에는 관리자에게 문의하거나 개인 계정을 쓰세요.

## 설치 순서

설치는 일곱 단계입니다. 1·2·4·5·7단계는 내가 하고, 3·6단계는 ChatGPT가 합니다.

### 1. 설치 문장 복사하기

[소개 페이지](https://jiwonschol.github.io/wonboard/)에서 설치 버튼을 누르면 설치 문장이 클립보드에 복사되고 ChatGPT가 새 탭으로 열립니다. 버튼을 쓰지 않으려면 [install-prompt.txt](./install-prompt.txt)를 열어 내용 전체를 복사하세요.

막혔을 때: 복사가 되지 않으면 소개 페이지의 「설치 문장 보기」를 펼쳐 글 전체를 직접 선택해 복사하세요.

### 2. 내 ChatGPT에 붙여넣기

ChatGPT에 유료 요금제 계정으로 로그인했는지 확인한 뒤, 새 대화의 입력창에 설치 문장을 붙여넣고 보냅니다. 문장을 고치지 않아도 됩니다.

보게 될 화면: ChatGPT가 Sites 작업을 시작하고, 진행 상황을 단계별로 알려 줍니다.

막혔을 때:

- ChatGPT가 일반 대화로만 답하고 Sites 작업을 시작하지 않으면, 입력창에서 `@Sites`를 직접 골라 넣은 뒤 문장을 다시 보내세요. 공식 문서는 `@Sites`를 언급하거나 프롬프트에 website라는 말을 넣으면 Sites 작업이 시작된다고 안내합니다.
- Sites 메뉴 자체가 보이지 않으면 요금제와 지역을 확인하세요. 웹에서는 **More > Sites** 또는 chatgpt.com/sites 에서 Sites를 볼 수 있습니다.

### 3. ChatGPT가 코드를 가져와 배포하기

ChatGPT가 원보드 저장소의 코드를 가져와 포함된 설정 그대로 빌드하고, 글을 담을 데이터베이스와 사진을 담을 파일 저장소를 만들고, 내 사이트로 배포합니다. 설치 문장은 사이트 접근 범위를 새 사이트의 처음 상태 그대로 두라고 시킵니다. 처음 상태에서는 소유자만 사이트를 열 수 있고, 회사나 학교 워크스페이스에서는 워크스페이스 관리자도 열 수 있습니다. 이 범위는 Sites가 정하는 것이고, 원보드의 소유자 확인과는 별개입니다. 사이트를 열 수 있는 사람이라도 연결된 소유자 계정이 아니면 원보드는 글과 사진을 내주지 않습니다.

보게 될 화면: 작업 도중 ChatGPT가 저장소 만들기나 배포를 승인해 달라고 물을 수 있습니다. 내용을 읽고 승인하세요. 끝나면 ChatGPT가 `chatgpt.site`로 끝나는 사이트 주소를 알려 줍니다. 얼마나 걸리는지는 다른 계정에서 재 본 적이 없습니다.

막혔을 때:

- ChatGPT가 저장소를 직접 가져오지 못한다고 하면 [코드 ZIP 파일](https://github.com/jiwonschol/wonboard/archive/refs/heads/main.zip)을 내려받아 같은 대화에 첨부하세요. 설치 문장도 이 경우에 그렇게 안내하라고 시킵니다.
- ChatGPT가 원보드와 다르게 생긴 새 사이트를 만들어 버렸다면 그 사이트는 원보드가 아닙니다. 「새로 만들지 말고 저장소의 코드를 그대로 배포해 주세요」라고 다시 요청하세요.
- 빌드나 배포가 실패하면 ChatGPT가 알려 준 오류 내용을 그대로 복사해 [문제 알리기](#문제-알리기)로 보내 주세요. 저장소에는 연결 설정과 새 설치용 DB 마이그레이션이 포함돼 있습니다. ChatGPT가 설정이나 코드를 새로 만들지 않도록 하고, 실패한 명령과 오류를 함께 알려 주세요.
- 요금제 한도에 닿았다는 안내가 나오면 원보드가 풀 수 없는 제한입니다. ChatGPT가 보여 주는 한도 안내를 따르세요.

### 4. 사이트를 열고 로그인하기

ChatGPT가 알려 준 주소를 브라우저에서 엽니다.

보게 될 화면: “원보드 설치가 아직 끝나지 않았어요.”라는 안내와 “설치 상태 다시 확인”, “ChatGPT로 로그인” 버튼이 보입니다. 아직 내 계정이 소유자로 연결되지 않아서 나오는 정상 화면입니다. 같은 화면의 “단계별 설치 안내”를 누르면 이 문서가 열립니다. “ChatGPT로 로그인”을 누르면 ChatGPT 로그인 화면으로 넘어갑니다. 처음 로그인할 때는 이 사이트에 내 기본 프로필을 공유할지 묻는 동의 화면이 나올 수 있습니다. 만든 사람의 계정에서는 이름·사용자명·이메일·프로필 사진이 표시됐고 대화 기록은 포함되지 않았습니다.

막혔을 때:

- 사이트가 열리지 않고 ChatGPT 로그인이나 접근 권한 화면만 나오면, 사이트를 만든 계정과 같은 계정으로 브라우저에 로그인했는지 확인하세요.
- “Site에 연결하지 못했어요.”로 시작하는 안내가 나오면 잠시 뒤 다시 시도하세요. 계속되면 배포가 끝나지 않았을 수 있으니 ChatGPT에 배포 상태를 물어보세요.

### 5. 연결 ID를 ChatGPT에 전달하기

로그인하고 돌아오면 같은 화면에 “계정 연결 정보”가 생깁니다. 이것을 펼치고 “연결 정보 확인”을 누르면 영문과 숫자로 된 연결 ID가 나옵니다. 이 값을 복사해, 설치를 진행하던 ChatGPT 대화에 붙여넣습니다. ChatGPT는 이 값을 사이트의 환경 값 `WONBOARD_OWNER_ID`로 저장합니다.

이 단계가 있는 이유: 원보드는 로그인에 성공한 아무나 소유자로 받아들이지 않습니다. 설치한 사람이 자기 연결 ID를 사이트 설정에 넣어야 그 계정만 글과 사진을 열 수 있습니다. 연결 ID는 이 사이트 안에서 내 로그인 계정을 가리키는 값이고 비밀번호가 아닙니다. 확인하는 것만으로는 소유자가 되지 않고 자료가 공개되지도 않습니다.

알아둘 점: 원보드는 Sites가 서버에 넘겨 주는 로그인 사용자 식별값으로 소유자를 가려냅니다. 이 값은 Sites 공식 문서의 로그인 항목에 나와 있지 않고, 만든 사람의 계정에서 동작하는 것만 확인했습니다. 다른 계정에서 값이 어떻게 나오는지는 확인되지 않았습니다.

막혔을 때:

- “계정을 확인하지 못했어요. 연결 상태를 확인하고 다시 시도해주세요.”가 나오고 다시 눌러도 같으면, 내 계정에서는 이 식별값이 전달되지 않는 것일 수 있습니다. 이 경우 지금 방식으로는 설치를 끝낼 수 없습니다. [문제 알리기](#문제-알리기)로 꼭 알려 주세요.
- ChatGPT가 환경 값을 직접 저장하지 못한다고 하면 내가 직접 넣을 수 있습니다. ChatGPT에서 **Sites**를 열고 해당 사이트의 **More actions > Settings**에서 이름 `WONBOARD_OWNER_ID`, 값에 연결 ID를 넣어 저장한 뒤, ChatGPT에 「저장한 버전을 다시 배포해 주세요」라고 요청하세요. 한국어 화면에서는 메뉴 이름이 다를 수 있습니다.

### 6. ChatGPT가 다시 배포하기

환경 값은 다시 배포해야 적용됩니다. ChatGPT가 앞서 저장한 버전을 다시 배포하고, 끝났다고 알려 줍니다.

막혔을 때: ChatGPT가 다시 배포하지 않고 끝냈다면 「환경 값을 적용하려면 저장한 버전을 다시 배포해 주세요」라고 요청하세요.

### 7. 설치 상태 확인하고 시작하기

사이트로 돌아가 “설치 상태 다시 확인”을 누릅니다.

보게 될 화면: 내 이름과 함께 “시작 전에 확인해주세요.”라는 안내가 나오고, 글과 사진이 어디에 저장되고 언제 공개되는지를 설명하는 항목 네 개가 보입니다. 내용을 읽고 “자료가 저장되는 곳과 사진이 공개되는 시점을 이해했습니다.”에 표시한 뒤 “내 글쓰기 공간 열기”를 누르면 글 목록과 편집기가 열립니다. 여기까지 오면 설치가 끝난 것입니다.

막혔을 때:

- 여전히 “원보드 설치가 아직 끝나지 않았어요.”가 보이면 환경 값이 적용되지 않은 것입니다. ChatGPT에 환경 값 이름이 `WONBOARD_OWNER_ID`가 맞는지, 다시 배포가 끝났는지 확인해 달라고 하세요.
- “다른 계정의 글쓰기 공간입니다. 이 Site를 설치한 계정으로 로그인해주세요.”가 보이면 저장한 연결 ID와 지금 로그인한 계정이 다릅니다. 5단계에서 연결 ID를 확인한 계정으로 로그인했는지, 값을 일부만 복사하지 않았는지 확인하세요.

## 설치한 뒤

- **사진 공개와 사이트 접근 범위는 따로입니다.** 원보드에서 사진을 공개로 등록해도, 사이트 접근 범위가 처음 상태 그대로면 다른 사람에게는 사진이 보이지 않습니다. 게시판에 붙인 사진이 남에게 보이게 하려면 Sites의 공유 설정에서 사이트 접근 범위를 넓혀야 합니다. 범위를 넓혀도 글 목록·초안·원본 사진은 소유자 계정으로만 열립니다. 만든 사람의 사이트에서 로그인하지 않은 요청이 거절되는 것까지는 확인했고, 다른 실제 계정으로 로그인했을 때 막히는지는 아직 확인하지 못했습니다.
- **ZIP 백업을 따로 보관하세요.** Sites는 베타이고 계정의 한도에 닿으면 공개 사진이 표시되지 않을 수 있습니다.
- **편집자 초대는 신중하게.** 워크스페이스에서 사이트 편집자로 초대한 사람은 초안을 포함한 실제 데이터를 읽을 수 있습니다. [공동 편집 안내](https://learn.chatgpt.com/docs/sites?surface=app#collaborate-on-a-site)
- **저장 위치와 밖으로 나가는 것**은 [개인정보·저장 안내](https://jiwonschol.github.io/wonboard/privacy.html)에 판별로 적혀 있습니다. 편집 화면의 「더 보기」에서도 열 수 있습니다.
- **새 버전으로 올리기**는 아직 안내가 없습니다. 베타 동안 따로 알립니다.

## 그만 쓰는 방법

1. 원보드에서 중요한 글과 사진을 ZIP으로 백업합니다.
2. 잠시 닫아 두기만 하려면 Sites의 공유 설정에서 접근 범위를 나 또는 고른 사람만 열 수 있게 좁힙니다. 사이트와 자료는 남습니다.
3. 완전히 지우려면 ChatGPT에서 **Sites**를 열어 해당 사이트를 찾고 **Delete site**를 고른 뒤, 안내에 따라 사이트 이름(slug)을 입력하고 **Permanently delete**를 누릅니다. [공식 삭제 안내](https://learn.chatgpt.com/docs/sites?surface=app#take-down-or-delete-a-site)

삭제한 사이트는 되살릴 수 없습니다. 사이트에 연결된 저장소의 자료가 어디까지 지워지는지는 삭제 화면의 안내를 확인하세요. 이미 게시판에 붙인 사진을 다른 사람이 내려받은 사본은 회수되지 않습니다. 원보드에는 가입이 없으므로 따로 탈퇴할 계정도 없습니다.

## 확인된 것과 확인되지 않은 것

| 내용 | 상태 |
| --- | --- |
| 만든 사람의 계정에서 설치, 로그인, 소유자 연결, 글·사진 저장 | 한 번 확인 |
| 다른 계정에서의 설치 전체 | 확인되지 않음 |
| ChatGPT가 저장소 주소만으로 코드를 가져오는지 | 확인되지 않음(확인된 것은 ZIP 첨부) |
| 다른 계정에서 연결 ID가 나오는지 | 확인되지 않음 |
| 설치 링크, 템플릿 복제, 문장이 미리 채워진 ChatGPT 링크 | 공식 문서에 없어 쓰지 않음(2026-10-06 확인) |
