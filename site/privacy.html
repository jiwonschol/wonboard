개인정보·저장 안내

원보드는 중앙 서버, 회원 DB, 분석 도구를 두지 않습니다. 글과 사진은 내가 설치한 곳에만 저장되고, 원보드를 만든 쪽으로는 아무것도 오지 않습니다.

이 안내는 원보드 기준이며, 판(版)마다 저장 위치와 밖으로 나가는 것이 다릅니다. 내가 쓰는 판은 넓은 화면에서 편집 화면 위쪽 막대 오른쪽에 적혀 있습니다. “내 ChatGPT Site”는 Sites판, “이 기기에 보관”은 데스크톱판, “이 브라우저에 보관”은 로컬 웹입니다.

Sites판 — 내 ChatGPT 사이트에 설치한 원보드

저장 위치

  • 글, 원본 사진, 첨부 파일은 내 ChatGPT 사이트에 딸린 데이터베이스와 파일 저장소에 저장됩니다. 이 저장소는 OpenAI가 운영하는 Sites에 있고, 원보드를 만든 쪽은 접근할 수 없습니다.
  • 같은 데이터베이스에 소유자의 ChatGPT 사용자 ID, 시작 안내를 확인한 시각, 그때 고른 화면 언어가 한 줄 저장됩니다. 소유자 계정을 가려내는 데 씁니다.
  • 브라우저에는 화면 언어, 개인 맞춤법 사전, 글꼴 안내를 본 기록이 남습니다. 사이트에 저장하지 못한 편집 내용이 있으면 복구용 사본도 이 브라우저에 남습니다.

밖으로 나가는 것

  • 공유한 사진. 「공유하기」에서 공개를 확인한 사진에만 외부 주소가 생깁니다. 주소를 아는 사람은 누구나 사진을 보거나 복사할 수 있습니다. 표를 이미지로 바꿔 공유하면 그 이미지도 같습니다. 초안 자체는 공개되지 않습니다.
  • 공유 글 사본과 공개 파일 링크. 직접 만든 경우에만 생기고, 링크를 아는 사람이 볼 수 있습니다. 파일 보관함에서 철회하거나 지울 수 있습니다.
  • 미리보기의 영상. 글에 넣은 YouTube·Vimeo 영상은 편집 중에는 링크 카드로만 보입니다. 「미리보기」를 열면 플레이어를 불러오고, 이때 내 브라우저가 영상 제공자(youtube-nocookie.com 또는 player.vimeo.com)에 연결됩니다.
  • 외부 이미지 불러오기는 하지 않습니다. 원보드 화면은 다른 사이트의 이미지를 불러오지 않습니다. 붙여넣은 글에 들어 있는 원격 이미지는 받지 않고, 내가 넣은 사진 파일만 표시합니다.
  • 공유한 사진을 게시판에 붙이면, 그 글을 읽는 사람의 브라우저가 내 사이트에서 사진을 받아 갑니다. 이 요청은 OpenAI의 Sites가 처리합니다.
  • 로그인은 ChatGPT 로그인입니다. 사이트는 로그인한 방문자의 ChatGPT 사용자 ID를 소유자 확인에 쓰고, 전달되는 이름·이메일은 화면에 보여 주는 데만 쓰며 저장하지 않습니다.

알아둘 것

  • 워크스페이스에서 사이트 편집자로 초대한 사람은 초안을 포함한 실제 데이터를 읽을 수 있습니다. 원보드의 소유자 확인은 이 접근을 막지 못합니다.
  • 호스팅, 접속 기록, 방문 통계는 OpenAI가 자체 약관에 따라 운영합니다. ChatGPT Sites 이용약관과 Sites 방문 통계 안내를 확인하세요.
  • 사이트를 다른 사람이 방문하게 한다면, 방문자에게 정보의 수집·이용을 설명할 책임은 사이트를 설치한 본인에게 있습니다.
  • 공개를 철회하면 사진 주소가 꺼지지만, 이미 내려받았거나 다른 곳에 복사된 사본은 회수되지 않습니다.

데스크톱판 — 직접 빌드해 쓰는 Mac 앱

저장 위치

  • 글과 사진은 이 컴퓨터에만 저장됩니다. macOS에서는 보통 ~/Library/Application Support/Wonboard/library/입니다.
  • 자료는 암호화하지 않습니다. 이 컴퓨터의 사용자 계정에 접근할 수 있는 사람은 읽을 수 있습니다.
  • 로그인이 없고 계정 정보를 받지 않습니다.

밖으로 나가는 것

  • 공유한 사진: 없습니다. 데스크톱판에는 공유 기능이 없어 사진이나 글을 어디에도 올리지 않습니다. 「PC 저장」은 이 컴퓨터에 파일을 만들 뿐입니다.
  • 미리보기의 영상. Sites판과 같습니다. 「미리보기」를 열 때만 영상 제공자에 연결됩니다.
  • 외부 이미지 불러오기는 하지 않습니다. Sites판과 같습니다.
  • 글 안의 링크나 이 안내를 누르면 기본 브라우저가 그 주소를 엽니다.
  • 우클릭 메뉴의 맞춤법 추천은 macOS의 맞춤법 검사기를 씁니다.

데스크톱판에서 Sites판으로, 또는 그 반대로 글을 옮기는 길은 ZIP 백업과 「백업 가져오기」입니다. 두 곳의 글은 자동으로 맞춰지지 않습니다.

로컬 웹 — 개발자가 자기 컴퓨터에서 띄우는 미리보기

저장 위치

  • 글과 사진은 그 브라우저의 저장 공간에만 저장됩니다. 암호화하지 않으며, 브라우저나 사용자가 저장 공간을 비우면 사라집니다.
  • 로그인은 같은 컴퓨터에서 도는 개발 서버가 확인하는 1인용 테스트 로그인입니다. 아이디와 비밀번호는 그 컴퓨터의 설정 파일에 있습니다.

밖으로 나가는 것

  • 공유한 사진: 없습니다. 공유 기능이 없습니다.
  • 미리보기의 영상과 외부 이미지는 다른 판과 같습니다.

어느 판에서도 수집하지 않는 것

  • 원보드를 만든 쪽 서버로 가는 글, 사진, 계정 정보, 사용 기록이 없습니다. 그런 서버가 없습니다.
  • 분석 도구, 광고, 추적 코드가 없습니다.
  • 원보드 회원 가입과 회원 DB가 없습니다.
  • 맞춤법 검사는 내 브라우저(또는 앱) 안에서 돌고, 글을 밖으로 보내지 않습니다.
  • 글꼴은 원보드에 들어 있는 파일을 쓰고, 외부 글꼴 서버에 연결하지 않습니다.

이 안내 페이지와 원보드 소개 페이지는 GitHub Pages에 있습니다. 이 페이지를 열면 GitHub이 접속을 처리합니다.

지우는 방법

  • Sites판: 중요한 글을 ZIP으로 백업한 뒤 ChatGPT의 Sites에서 사이트를 지웁니다. 순서는 그만 쓰는 방법에 있습니다.
  • 데스크톱판: 앱을 지우고 위 저장 폴더를 지웁니다.
  • 로컬 웹: 브라우저에서 그 주소의 사이트 데이터를 지웁니다.

문의

궁금한 점이나 문제는 GitHub Issues에 남겨 주세요. GitHub Issues는 공개된 곳이니 연결 ID, 이메일, 사이트 주소처럼 나를 가리키는 값은 지우고 올려 주세요.

Privacy and storage

Wonboard has no central server, no member database and no analytics. Your writing and photos stay where you installed Wonboard; nothing is sent to the people who make it.

This page describes Wonboard . Storage differs by edition. On a wide screen, the right side of the top bar in the editor shows yours: “My ChatGPT Site” is the Sites edition, “On this device” is the desktop edition, and “Saved in this browser” is the local web preview.

Sites edition — Wonboard installed on your own ChatGPT site

Where data is stored

  • Documents, original photos and attached files are stored in the database and file storage attached to your ChatGPT site. OpenAI operates that storage as part of Sites. The makers of Wonboard cannot reach it.
  • The same database keeps one row with the owner's ChatGPT user ID, the time the owner acknowledged the start notice, and the interface language chosen then. It is used to recognise the owner account.
  • Your browser keeps the interface language, your personal spelling dictionary and whether you have seen the font notice. If edits could not be saved to the site, a recovery copy is also kept in this browser.

What leaves

  • Photos you share. Only photos you confirm in Share get public URLs. Anyone with a URL can view or copy the photo. Tables shared as images work the same way. The draft itself is not published.
  • Shared writing copies and public file links. They exist only if you create them, and anyone with the link can open them. You can revoke or delete them in the file library.
  • Videos in Preview. YouTube and Vimeo videos appear as link cards while you edit. Opening Preview loads the player, and your browser then connects to the provider (youtube-nocookie.com or player.vimeo.com).
  • External images are not loaded. Wonboard's screens do not load images from other sites. Remote images in pasted content are not accepted; only photo files you add are shown.
  • When you paste shared photos into a community post, readers' browsers fetch them from your site. OpenAI's Sites serves those requests.
  • Sign-in is ChatGPT sign-in. The site uses a signed-in visitor's ChatGPT user ID to check ownership. An available name or email is used for display only and is not stored.

Good to know

  • People you invite as workspace editors of the site can read its live data, including drafts. Wonboard's owner check does not prevent this.
  • OpenAI operates hosting, access logs and visit statistics under its own terms. See the ChatGPT Sites terms and the Sites analytics guide.
  • If you let other people visit your site, you, the person who installed it, are responsible for explaining to them what is collected and how it is used.
  • Withdrawing a photo turns its URL off. Copies already downloaded or cached elsewhere cannot be recalled.

Desktop edition — a Mac app you build yourself

Where data is stored

  • Documents and photos are stored on this computer only, normally in ~/Library/Application Support/Wonboard/library/ on macOS.
  • Data is not encrypted. Anyone with access to this computer's user account can read it.
  • There is no sign-in and no account information is received.

What leaves

  • Photos you share: none. The desktop edition has no sharing, so it uploads nothing. Save to PC only writes a file on this computer.
  • Videos in Preview. Same as the Sites edition: a connection to the provider is made only when Preview opens.
  • External images are not loaded. Same as the Sites edition.
  • Clicking a link in a document or in this guide opens that address in your default browser.
  • Spelling suggestions in the right-click menu come from the macOS spell checker.

To move a document between the desktop edition and the Sites edition, download a ZIP backup and open it with Restore backup. The two are not kept in sync automatically.

Local web — a preview developers run on their own computer

Where data is stored

  • Documents and photos are stored only in that browser's storage. They are not encrypted, and they disappear if the browser or the user clears the storage.
  • Sign-in is a single-user test login checked by the development server on the same computer. The ID and password live in a settings file on that computer.

What leaves

  • Photos you share: none. There is no sharing.
  • Videos in Preview and external images behave as in the other editions.

Not collected in any edition

  • No writing, photos, account information or usage records go to a server run by the makers of Wonboard. No such server exists.
  • No analytics, advertising or tracking code.
  • No Wonboard sign-up and no member database.
  • Spell checking runs inside your browser or app and does not send your text anywhere.
  • Fonts are bundled with Wonboard; no external font server is contacted.

This page and the Wonboard introduction page are hosted on GitHub Pages. Opening this page is handled by GitHub.

Deleting your data

  • Sites edition: back up important documents as ZIP, then delete the site in ChatGPT Sites. The steps are in the Korean guide, How to stop using Wonboard.
  • Desktop edition: remove the app and delete the storage folder above.
  • Local web: clear the site data for that address in the browser.

Contact

Ask questions or report problems at GitHub Issues. Issues are public, so remove values that identify you, such as a connection ID, an email address or your site address.
